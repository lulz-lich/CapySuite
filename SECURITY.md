# Security Policy

CapySuite is a local-first operations and documentation platform for authorized security work. It does not perform exploitation, credential validation, phishing, command and control, persistence, or destructive actions.

## Reporting Security Issues

If you identify a security issue in CapySuite, please open a private advisory or contact the maintainer through the repository owner profile. Do not include real credentials, customer data, tokens, exploit payloads, or sensitive evidence in public issues.

## Data Handling

- Do not paste real secrets or customer data into demo workspaces.
- Use the Evidence Sanitizer before copying text into reports.
- Keep `.env` files local; `.env.example` is provided only as a placeholder for future integrations.
