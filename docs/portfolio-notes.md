# Portfolio Notes

CapySuite is positioned as a flagship Red Team operations platform rather than an exploit toolkit. That distinction is intentional: the project demonstrates offensive-security maturity, assessment workflow design, evidence discipline, OPSEC awareness, and reporting quality without creating unsafe functionality.

## What It Demonstrates

- Product thinking for authorized Red Team operations.
- React and TypeScript architecture.
- Domain modeling for engagements, findings, evidence, OPSEC notes, and attack-chain steps.
- Local-first persistence and import/export workflows.
- Safe MITRE ATT&CK mapping.
- A Safe Hacker Workbench with local-only analysis helpers.
- Safe playbooks, executive auto-briefing, and command-center search.
- MITRE ATT&CK Navigator layer export.
- Professional dark operator UI without parody visuals.
- Automated tests for exports, analytics, and JSON import.

## Talking Points

- The app avoids offensive automation by design.
- Evidence handling is metadata-first to reduce sensitive-data exposure.
- Readiness checks model real engagement hygiene.
- MITRE mapping is manual to keep operator judgment central.
- The local-first architecture can grow into a FastAPI-backed multi-user platform later.
